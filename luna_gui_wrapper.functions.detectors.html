luna_gui_wrapper.functions.detectors module

Timepix3 and Timepix4: which Luna tool, which raw files, which units.

Luna ships one converter per detector – tpx3dump for .tpx3, tpx4dump for .tpx4 – with the same process -i … -o … command line and the same HDF5 layout (PixelHits, Clusters, ExposureTimeBoundaries, same fields). What differs is the time base: per Luna’s own “Read data, Unit Conversion” example, ToA counts 1e-13 s on Timepix3 but 1e-16 s on Timepix4, and ToT is whole nanoseconds (25 ns steps) on Timepix3 but the ToA tick on Timepix4. Anything that reads times or ToT out of a file has to know which it is.

Qt-free.

luna_gui_wrapper.functions.detectors.detect_from_file(f, sample=100000)[source]

Which detector wrote this open h5py file? A Detector, or None.

Decided from ToT, the one field whose scale separates the two: a Timepix3 pixel ToT is at most 1023 x 25 ns = 25 575, while any non-zero Timepix4 ToT is at least 1 953 125. None when the file holds no non-zero ToT to judge by (empty, or a –raw-only file whose ToT is all zero).
