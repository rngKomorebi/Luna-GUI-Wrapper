luna_gui_wrapper.functions.naming.effective_template(template: str, luna_comment: str) → str[source]

The template actually used once a Luna comment is typed in.

A comment typed on the Advanced tab (what was changed for this run, e.g. “–eps-t 300 ns”) goes on the end of the name. Empty -> the template is unchanged. A template that already places {luna_comment} itself is left alone, so the comment never appears twice.

luna_gui_wrapper.functions.naming.measurement_context(tpx3: Path) → dict[source]

Collect naming fields for one .tpx3 file.

ASI writes <campaign>/<Measurement_…>/raw/<file>.tpx3 with measurement_metadata.json and comment.txt in the measurement folder, so we walk up a few levels looking for them.

luna_gui_wrapper.functions.naming.migrate_template(cfg) → bool[source]

One-time move of an existing config onto the new default name.

Without this the change would only reach fresh installs, since a saved config always carries an explicit “template”. Runs once (guarded by template_version) and only when the saved value is a superseded default, so a deliberate choice of “{stem}” is never overwritten.

luna_gui_wrapper.functions.naming.sanitize(text) → str[source]

Make a value safe to drop into a filename.
